# Rustik Plank

Next.js 14 + Tailwind CSS + MongoDB/Mongoose furniture e-commerce demo.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Create `.env.local` and set your MongoDB URI:

```bash
MONGODB_URI=your_connection_string
```

3. Seed products:

```bash
node scripts/seed.js
```

4. Start the dev server:

```bash
npm run dev
```

Open `http://localhost:3000`.
